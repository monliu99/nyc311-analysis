Last week's count for the same weekday is by far the most valuable feature for predicting daily complaint volume, since it carries the current level of demand (a campaign, an outbreak, a backlog) that calendar features cannot see, and it is known a week ahead. To be candid, the full forecasting model built here, which adds the weekday, holidays, month, weather, a long-run trend and a 2020 indicator to that count, did not beat the simple rule of expecting the same number as on that weekday last week, as its average miss was 13.0% against 10.3% in 2019, 18.2% against 13.4% in 2020, and 13.3% for both in 2021.

Each of those years was forecast by a model trained only on earlier years, and the average miss is the typical gap between forecast and actual as a share of the actual count. The other features do describe real patterns (in a model fitted to all the days, Sundays run 18.7% below Mondays and federal holidays 28.6% below other days), but last week's same-weekday count likely already contains the weekday and most of the season, and dropping either the weekday or the long-run trend from the model cut its error by more than 3 points in both 2019 and 2020. A model with last week's count alone did better than both the full model and the simple rule in every test year (9.9%, 12.7% and 13.0%), which means that a production model is likely best built up from that count, adding the month (worth 0.2 points) and other features back only where they prove themselves on unseen years, and saving weather, as forecasts, for the complaint types it moves in Q6.

When the same features are tested against response times, they matter much less. For complaints opened on each day, every feature's correlation with the mix-adjusted time to close (compared with the citywide typical time for the same complaint type and year) is small, the largest being +0.13 for weekends, and held together the clearest link is that complaints opened on a Friday take 17.5% longer than Monday's relative to typical, likely because the weekend falls in between. A day's own volume shows no link once the calendar and weather are held fixed, which means that there is no sign in this data that busy days slow closures.

These are correlations, not causes, since calendar, weather and volume all move together, and observed weather overstates what a real forecast could use. In addition, because the like-for-like measure compares each complaint with others of its type in the same year, it cannot say whether response times improved from one year to the next, which would need a separate test.
